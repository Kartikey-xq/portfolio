# Portfolio Assets Directory

This directory stores all production screenshots and video captures for Kartikey Joshi's Shopify Developer Portfolio.

## Folder Structure

```text
public/portfolio-assets/
├── images/           <-- Put all .png, .jpg, .jpeg, .webp screenshots here
├── videos/           <-- Put all .mp4, .webm demo videos here
├── ASSET-GUIDE.md    <-- Detailed guide on what to capture
└── README.md         <-- This file
```

## Quick Naming Reference

Add files using these exact filenames:

### Images (put in `images/`):
- `01-custom-sections-built-01.png`
- `01-custom-sections-built-02.png`

- `04-quick-size-guide.mp4`
- `05-scroll-based-animations.mp4`
- `06-scrub-based-animation.mp4`

## How Detection Works

The website automatically scans and renders assets matching these filenames. You do **NOT** need to edit any React or TypeScript code when adding or replacing assets.

If any file is not yet uploaded, a subtle developer placeholder will be shown so the website layout remains intact.
